# COMP 163 – Assignment 4: College Life Adventure Game

## What the game is about
Make semester decisions (course load + study focus) that change GPA, study hours, stress, and social life, leading to multiple endings.

## Where each concept appears
- **if / elif / else:** Course load decision (Light/Standard/Heavy)
- **Comparison ops (>=, <=, ==, !=):** GPA checks to adjust hours/stress
- **Membership ops (in, not in):** Validate study focus from list
- **Logical ops (and, or, not):** Combined conditions in study focus logic
- **Identity ops (is, is not):** Type checks for GPA and study_hours
- **Nested ifs (2+ levels):** Final assessment branches (GPA → stress → social)
